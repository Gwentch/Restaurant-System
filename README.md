# Restaurant Management System

This is a simple desktop-based Restaurant Management System developed in **Java** using **JavaFX** and **Maven**. It was created as part of a coursework project to demonstrate core software engineering principles, GUI design, and basic data handling.

*This project uses JavaFX. If you face issues running it, make sure JavaFX is correctly set up in your IntelliJ SDK and VM options.*

## Features:
- Menu browsing
- Order booking, placement and tracking
- Staff interface (Waiter, Manager, Chef, Delivery Driver with their respective duties)
- Customer interface
- Customer account registration

## Technologies Used:
- **Java 17**
- **JavaFX**
- **SceneBuilder** (for UI prototyping)
- **Maven** (Project & dependency management)
- **IntelliJ IDEA** (IDE)
